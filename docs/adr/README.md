# Architecture Decision Records (ADR)

Dùng ADR cho quyết định có ảnh hưởng dài hạn.

Ví dụ:

```text
0001-use-ros2-jazzy.md
0002-esp32-own-low-level-safety.md
0003-use-slam-toolbox.md
0004-static-map-localization-strategy.md
0005-fleet-protocol-strategy.md
```

Không cần ADR cho sửa bug nhỏ.

Mỗi ADR dùng template `0000-template.md`.
